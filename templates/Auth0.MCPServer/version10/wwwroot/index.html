Complete your MCP server configuration

Your MCP server is registered with Auth0, but you still need to complete the configuration in the Auth0 Dashboard:

  • Set the JWT Profile to RFC 9068(see here).
  • Enable RBAC and Add Permissions in the Access Token.
  • Add the permissions tool:getsystemstate and tool:setsystemstate, and assign them to your users (see here).
  • Set the user access policy in Application Access to Allow (see here).

Configure your Auth0 tenant

Enable the Resource Parameter Compatibility Profile (see here) in Settings > Advanced of your tenant, and choose how MCP clients register with Auth0:

  • Client ID Metadata Document (CIMD): the client ID is an HTTPS URL pointing to a metadata document published by the client. It is recommended for production because it is more secure and scalable. Learn more about CIMD.
  • Dynamic Client Registration (DCR): clients register themselves at runtime. Enable it in Settings > Advanced and promote your connections to domain level. It applies to the whole tenant and lets anyone create applications in it. Learn more about DCR.

Note: The HTTP launch profile used by default in the MCP server project is for the development environment only.
